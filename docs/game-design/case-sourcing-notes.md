## Generated or inferred conclusions (6 cases carry a `sourceNote`)

Four cases had no final diagnosis at all in the source text (case-26 was
cut off mid-sentence). Their conclusions were generated by Claude per
explicit user instruction, and each carries a `sourceNote` in
`realCases.ts` saying so: case-16 (Kacper Sobczak), case-23 (Alicja
Cisek), case-26 (Klementyna Wróbel), case-29 (Paulina Górecka).

Two further cases carry a `sourceNote` for a narrower reason: the
diagnosis was inferred from clinical evidence rather than a literal
stated conclusion, unlike cases such as 8/14/15 where the source states
"melanoma" in prose even without a bracketed `{}` tag.
- case-28 (Ryszard Wolski): inferred from a specific, named dermoscopy
  finding (parallel ridge pattern), which is diagnostic-grade evidence
  for acral lentiginous melanoma.
- case-09 (Józef Baran): inferred from a full ABCDE criteria assessment
  described in the source (asymmetry, border irregularity, color
  variegation, diameter, evolution) — the source never names a
  diagnosis, so this is Claude's clinical interpretation of the
  documented findings, not a transcription of a stated conclusion.

Every other case's `sourceNote` is `null`.
